# Scan_CountStock

เว็บเปิดในมือถือ สแกน QR / บาร์โค้ด เพื่อรับสต๊อก แล้วส่งออกเป็นไฟล์ Excel (.xlsx)

## วิธีใช้
1. เปิดเว็บ (ต้องเป็น HTTPS เพื่อให้เปิดกล้องได้) → กด "เปิดกล้อง" → อนุญาตกล้อง
2. สแกนสินค้า — รหัสเดิมจะ +1 อัตโนมัติ (หรือติ๊ก "ถามจำนวน" เพื่อกรอกจำนวนต่อครั้ง)
3. แก้ไขจำนวน / ลบรายการได้ในรายการด้านล่าง หรือพิมพ์รหัสเองได้
4. กด "ส่งออก Excel" → ได้ไฟล์ 2 ชีต: สรุปสต๊อก และ ประวัติสแกน

ข้อมูลเก็บในเครื่อง (localStorage) ปิดหน้าเว็บแล้วไม่หาย

## ใช้งานออนไลน์
ไฟล์เดียว `index.html` — เปิดใช้ผ่าน GitHub Pages (Settings → Pages → branch ของโปรเจกต์ / root) หรือ deploy ขึ้น Vercel ก็ได้
